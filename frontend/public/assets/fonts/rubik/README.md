# Rubik

Unmodified Google Fonts **v31** variable WOFF2 files, downloaded 2026-11-06 from
the stylesheet previously used by the application:

https://fonts.googleapis.com/css2?family=Rubik:ital,wght@0,300..900;1,300..900&display=swap

`rubik.css` preserves all original unicode ranges, normal/italic styles and the
300–900 weight range. Only the source URLs changed to local filenames. Browsers
download only the subsets needed by the page. The normal Latin subset is
preloaded for the homepage heading; other subsets/styles load on demand.

The SIL Open Font License is included in `OFL.txt`, sourced from
https://github.com/google/fonts/blob/main/ofl/rubik/OFL.txt.
